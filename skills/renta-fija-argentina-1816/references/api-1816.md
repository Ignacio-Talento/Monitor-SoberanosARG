# Referencia — API de 1816 (renta fija argentina)

Detalle completo para respaldar la skill `renta-fija-argentina-1816`. Fuente de verdad:

## 1. Endpoints

| Método | Path | Uso |
|---|---|---|
| POST | `/v1/auth/token` | Auth: `{apiKey, module:"mercado"}` → token JWT (24 h). |
| GET | `/v1/creditos/balance` | Balance de créditos (gratis). |
| GET | `/v1/mercado/indicadores` | Precios/indicadores (foto de un día). |
| GET | `/v1/mercado/indicadores/{ticker}` | Igual, para un ticker puntual. |
| GET | `/v1/mercado/instrumentos` | Buscar instrumentos. Requiere `texto` (≥2 chars) **o** `curvaId`. Param `soloPerforming` (true/false). |
| GET | `/v1/mercado/series` | Series históricas. Rango ≤ 1 año por request. |
| GET | `/v1/mercado/curvas` | Buscar curvas por `texto` (≥2 chars). Devuelve `{id, name, convencionTna}`. |

El script `precios_1816.py` ya maneja auth, token cache, rate-limit, batching de 50 tickers
y auto-chunking de series >1 año. Métodos: `precios()`, `series()`, `instrumentos()`,
`balance_creditos()`. Para curvas o el endpoint por-ticker, usar `c._get(path, params)`.

## 2. Campos de precios (`indicadores`) — `CAMPOS_VALIDOS`

`convencionTna, currentYield, denominacion, duration, durationMod, fechaLiquidacion,
fechaOperacion, fuente, moneda, paridad, plazo, precioClean, precioDirty, spread, tea, tem,
ticker, tna, ultimaOperacion, volumenMontoDiario, volumenNominalDiario`

## 3. Campos de series (`series`) — `CAMPOS_SERIES_VALIDOS`

`currentYield, duration, durationMod, paridad, precioClean, precioDirty, spread, tea, tem,
tna, valorTecnico, volumenMontoDiario, volumenNominalDiario`

Diferencias con precios: series **no** incluye campos no temporales (`denominacion`, `moneda`,
`ticker`, `fechaOperacion`, `ultimaOperacion`, etc.) y **agrega `valorTecnico`**.

### Significado y unidades
| Campo | Qué es | Unidad |
|---|---|---|
| precioClean | Precio limpio (sin intereses corridos) | ARS / CCL / MEP |
| precioDirty | Precio sucio (con intereses corridos) | ARS / CCL / MEP |
| paridad | Precio sobre valor técnico | fracción (0,85 = 85%) |
| tna | Tasa nominal anual | fracción (0,09 = 9%) |
| tea | Tasa efectiva anual | fracción |
| tem | Tasa efectiva mensual | fracción |
| currentYield | Rendimiento corriente | fracción |
| spread | Margen (TNA) sobre la curva | fracción |
| duration | Duración | años |
| durationMod | Duración modificada | años |
| valorTecnico | Valor técnico cada 100 VN (solo series) | ARS |
| volumenMontoDiario | Monto operado en el día | ARS |
| volumenNominalDiario | Nominales operados en el día | VN |
| ultimaOperacion | Momento de la última operación (solo precios) | fecha/hora |

## 4. Parámetros de mercado (opcionales)

- `fuente`: `byma` (default) · `mae` · `homo-1816`.
- `moneda`: `ars` (default) · `ccl` · `mep`. Para instrumentos en moneda ≠ ARS, las
  cotizaciones se dividen por CCL.
- `plazo`: entero, días de liquidación (default 1).
- `fechaOperacion` (precios) / `fechaInicial`+`fechaFinal` (series): `AAAA-MM-DD`.
- `convencionTna`: `30-360, 90-360, 180-360, 32-365, 90-365, 180-365, plazo-rem`
  (default: la de la curva del instrumento).

## 6. Límites y costos

- **Costo precios** = nº tickers × nº campos.
- **Costo series** = nº tickers × nº campos × nº días con dato (verificado: 1×1×6 = 6; 1×2×6 = 12).
- Listar/buscar instrumentos: barato (relevar las 26 curvas costó ~29 créditos).
- Balance: gratis.
- Plan Mercado-Base: 100.000/día, 3.100.000/mes (reset 00:00 ART). Sin créditos → HTTP 402.
- Rate limit: 1 req/seg → HTTP 429 si se excede.
- Máx 50 tickers por consulta. Máx 1 año por serie.

## 7. Formas de respuesta

**Precios** (`indicadores`): `{ fechaOperacion, fuente, plazo, moneda, instrumentos: { TICKER: {campo: valor} } }`.

**Series**: `{ fechaInicial, fechaFinal, fuente, plazo, moneda, convencionTna,
instrumentos: { TICKER: { campo: [[fecha, valor], ...] } } }`. Cada campo es una lista de
tuplas `[fecha, valor]`; `valor` es `null` si no hay dato ese día.

## 8. Gotchas verificados

- La serie solo devuelve **días hábiles** (excluye finde y feriados ARG; p.ej. falta el
  09-jul, Día de la Independencia).
- El histórico arranca en el **inicio de cotización** del instrumento (AL30: 2020-09-07). No
  hay datos previos a ~2020 para los sondeados (CUAP/DICP en 2016-17: sin datos).
- `curvas` e `instrumentos` **exigen `texto` de ≥2 caracteres** (no listan todo con query vacío);
  para enumerar el universo, iterar `curvaId`.
- El rate-limit de 1 req/seg es **justo**: llamadas separadas de la CLI muy seguidas pueden
  dar 429 aunque cada proceso respete el segundo. Preferir un único proceso para lotes de
  llamadas; si persiste, subir `MIN_SEGUNDOS_ENTRE_REQUESTS` a 2.5-3.0.
- Arrays serializados como parámetros repetidos (`?tickers=AL30&tickers=GD30`): confirmado que
  la API los acepta así (es lo que hace `requests` por default).
